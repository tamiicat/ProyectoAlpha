# Frontend — Sistema Logístico FYAG (`frontend-react`)

Interfaz web desarrollada con React, Vite, React Router DOM y Bootstrap.

### Requisitos
* Node.js (v18 o superior)
* npm

### Variables de entorno
Crea un archivo `.env` en la raíz de `frontend-react` con las siguientes variables (solicitar las URLs reales al equipo):
```env
VITE_API_URL=URL_DEL_BACKEND
VITE_AUTH_URL=URL_DEL_SERVICIO_AUTH
```

### Ejecución
```bash
npm install
npm run dev
```

* Abre en el navegador `http://localhost:5173`.
