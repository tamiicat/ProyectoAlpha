# ProyectoAlpha

Sistema de Gestión Logística FYAG (Proyecto Alpha).

## Frontend (`frontend-react`)
Desarrollado con React, Vite, React Router DOM y Bootstrap.

### Requisitos
* Node.js (v18 o superior)
* npm

### Ejecución
```bash
cd frontend-react
npm install
npm run dev
```

* Abre en el navegador `http://localhost:5173`.
